Mining Control Room (MCR) Operation Toolkit

Studi Kasus: Otomatisasi Validasi Timesheet & Monitoring Unit Alat Berat

Tentang Proyek

Mining Control Room (MCR) Operation Toolkit adalah proyek independen yang dirancang untuk mengatasi tantangan operasional harian di sektor pertambangan. Proyek ini bertujuan untuk mengeliminasi human error dalam proses pencocokan data operasional antara laporan jam kerja operator (Timesheet) dan pembacaan fisik meteran alat berat (Hour Meter / HM), serta menyajikan visualisasi status unit secara real-time guna mempercepat pembuatan laporan manajemen.

Ms. Excel (Advanced) SQL (SQLite) Python (Pandas & Openpyxl) Streamlit Dashboard

Alur Kerja Sistem

Langkah 01

Simulasi Database Relasional

Membangun struktur database SQLite lokal (`mcr_data.db`) dengan tabel ternormalisasi `unit_rental` (30 unit alat berat) dan `timesheet` pencatatan harian.

Langkah 02

Validasi Otomatis & BAST

Skrip Python memvalidasi kesesuaian jam kerja dilaporkan vs selisih HM ($HM_{akhir} - HM_{awal}$). Sistem otomatis mendeteksi anomali (misal: selisih pada UNIT-003) dan mengekspornya ke Excel.

Langkah 03

Monitoring Dashboard

Antarmuka web interaktif berbasis Streamlit memonitor status aktivitas unit (Operasi, Standby, Breakdown) secara real-time untuk kebutuhan Daily Report.

Dampak Bisnis (Business Value)

Efisiensi Waktu

Memangkas proses audit rekapitulasi data operasional dari yang sebelumnya memakan waktu berjam-jam secara manual menjadi hanya beberapa detik.

Akurasi Finansial

Mencegah risiko over-payment tagihan vendor rental alat berat melalui deteksi dini diskrepansi sebelum proses BAST disetujui.

Pelaporan Responsif

Menyajikan metrik dan grafik status unit yang transparan untuk mendukung pengambilan keputusan cepat oleh manajemen MCR.
